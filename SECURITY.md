# 🔒 SECURITY.md – Vulnerability Reporting & Security Policy

## Security Commitments
Aseer AI prioritizes privacy and security, especially regarding Bring Your Own Key (BYOK) storage and local sandbox execution.

- **API Key Handling:** Client keys are encrypted in-transit and stored strictly client-side or in secure session memory.
- **Code Execution:** Web previews run in isolated sandboxed iFrames.

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT create a public issue. Email security details directly to the maintainer or open a private advisory.
